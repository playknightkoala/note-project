# Notes

Notion 式的筆記網站：自有帳號（邀請碼註冊，第一位註冊者為管理者）、BlockNote 區塊編輯器、頁面樹、資料庫表格視圖、全文搜尋、頁面歷史。單一 Docker 容器 + SQLite，資料與附件放在同一個 volume。

文件：[部署指南](docs/DEPLOY.md)、[分享筆記](docs/SHARING.md)、[架構與里程碑](docs/ARCHITECTURE.md)、[驗證紀錄](docs/VALIDATION.md)、[交接紀錄](docs/HANDOFF.md)、[開發指引](AGENTS.md)。

## 啟動

```powershell
docker compose up -d --build --wait
```

開啟 `http://127.0.0.1:8080/`（埠由 `.env` 的 `NOTES_PORT` 決定，只綁 loopback）。第一次開啟時建立管理者帳號；之後的使用者需要管理者在「設定 → 邀請碼」產生的邀請連結。資料在 named volume `notes_notes-data`。

要架到網際網路、備份與還原、放在 Cloudflare 後面：見 [docs/DEPLOY.md](docs/DEPLOY.md)。

## 功能

- **帳號**：邀請碼註冊（可用 `NOTES_SETUP_TOKEN` 保護第一個管理者帳號）、登入次數限制、請求大小上限、CSRF 防護（反向代理或 tunnel 後面請設 `NOTES_PUBLIC_ORIGIN`，見部署指南）、管理者可停用使用者與撤銷邀請碼。
- **頁面**：巢狀頁面樹（拖曳搬移）、最愛、垃圾桶（還原／永久刪除）、麵包屑、複製頁面、emoji 圖示、封面（漸層或上傳圖片，可調整位置）、全寬與小字體。
- **編輯器**：BlockNote 完整區塊（標題、清單、待辦、可摺疊、引用、程式碼、分隔線、表格、圖片、影片、音訊、檔案），`/` 區塊選單、`@` 提及頁面、`:` 表情符號，貼上或拖入檔案自動上傳；繁體中文介面與輸入法防護。
- **保存**：自動保存，以版本號防止兩個分頁互相覆蓋；衝突時可載入最新版本或以自己的內容覆蓋（被覆蓋的版本留在頁面歷史）；頁面歷史可預覽與還原。
- **離線筆記（PWA）**：一般筆記、資料庫、留言與附件都可在手機離線使用：開啟與編輯筆記、開啟資料庫並修改資料列／欄位／視圖、留言與表情反應、在筆記中加入圖片與檔案。連線開啟、恢復連線與切回前景時自動上傳並下載更新，顯示完成提示與最近完整同步時間。資料列逐格比對，只有同一格在兩邊都被修改才算衝突，不會靜默覆蓋。「離線與同步」可查看待同步項目、處理衝突、匯出草稿及設定附件快取容量（預設 500 MB）；附件上傳預設 90 MB。首次須連線準備介面與內容；手機需 HTTPS。不保證關閉後背景同步；搜尋、頁面歷史、最愛、搬移、垃圾桶、圖示／封面與新增資料庫仍需連線。操作與限制見 [OFFLINE.md](docs/OFFLINE.md)。
- **分享**：頁面可開啟不需登入的唯讀公開連結（可隨時關閉並換網址），或與本站其他帳號共用（以 email 個別指定；也可以設定登入的本站帳號開啟公開連結時可唯讀或可編輯。兩種權限都能留言與加表情）。每項分享可選範圍：只有此頁面、含子頁面，或連同資料庫。別人分享的頁面列在側欄「與我共用」，也能離線使用。見[分享筆記](docs/SHARING.md)。
- **版本與更新**：左下角顯示目前介面版號，可手動檢查更新；偵測伺服器新版後，自動顯示更新資訊 Modal，按「立即更新」套用新版。更新前保存筆記，保留待同步草稿、登入與附件快取；其他分頁會收到提醒並保留目前內容。
- **搜尋**：`Ctrl+K`（macOS `⌘K`）搜尋標題與內文，支援中英文與兩字查詢，含最近開啟與快速動作。
- **頁面內尋找與取代**：在筆記頁按 `Ctrl+F`（macOS `⌘F`）或頁面選單「尋找與取代」，尋找列顯示在右上角：不分大小寫、標出所有結果與目前第幾筆，`Enter`／`Shift+Enter` 切換；按取代圖示可逐筆取代或全部取代（一次復原即可還原）。唯讀共用頁與公開連結只能尋找。在尋找欄位再按一次 `Ctrl+F` 會改用瀏覽器自己的尋找。
- **資料庫**：表格／清單／看板共用資料，可新增、命名、切換與刪除視圖，各自保存排序、AND 篩選與顯示欄位。空表格提供兩列空白輸入位置，輸入後才建立資料；文字、數字、網址在格內編輯，Enter 或失焦儲存，核取方塊直接切換，底部「新增頁面」直接輸入。看板依單選欄位分組，可拖曳把手或用卡片選單移組。共七種屬性，資料列可開成完整頁面；每個資料庫最多 5,000 列、20 個視圖。
- **快捷鍵**：`Ctrl+K` 搜尋、`Ctrl+F` 頁面內尋找與取代、`Ctrl+\` 收合側邊欄、`Ctrl+Alt+N` 新增頁面（macOS 用 `⌘`）。
- **右鍵與文字選取**：頁面、側邊欄、資料庫欄位與資料列都有右鍵選單（鍵盤 `Shift+F10` 或選單鍵）。桌面選取內文會顯示緊湊格式面板，也可對選取文字按右鍵；手機保留原生選取選單，主動點「格式與段落」才開啟底部面板，中文組字期間隱藏入口。可轉換段落／標題／清單／引用／程式碼、調整文字格式、留言與加表情反應，切換工具時保留原選取範圍。留言可回覆、解決、重新開啟或確認後刪除整則討論；解決、刪除或移除最後一個表情（且沒有留言）後取消黃色標記，保留文字與其他討論。點擊黃色標記或「留言與反應」查看，已解決／已取消項目可切換顯示。輸入框、連結及未選取文字的編輯區保留原生選單，`Shift+右鍵` 可使用原生選單。
- **登入**：可勾選「記住帳號」，只記住帳號名稱，不存密碼。

登入狀態以持久 Cookie 保存，關閉瀏覽器後一般仍保持登入。伺服器在約 30 天沒有收到該 session 的有效請求後使其失效；持續使用時滑動延長，但從登入起最多 90 天。背景分頁的查詢也算有效請求。登出、清除 Cookie、帳號停用或其他裝置改密碼可提前結束登入。

不做的事：Joplin 匯入（已取消）、即時多人協作（共用的頁面以版本衝突處理同時編輯）、清單／看板以外的額外視圖、公式／關聯欄位。

## 開發

需要 Node 22 與 npm 10。

```bash
npm install
```

```bash
npm run dev
```

同時啟動 API（`http://127.0.0.1:8080`，資料寫在 `./data`）與 Vite 開發伺服器（`http://127.0.0.1:5173`，`/api` 代理到 API）。

```bash
npm run check
```

依序執行 typecheck、lint、test、build。容器啟動後可再跑 `npm run test:app -- http://127.0.0.1:8080` 做靜態安全檢查。

## 結構

- `src/shared`：zod schema、型別與純函式（前後端共用）。
- `src/server`：Hono API、SQLite（`node:sqlite`）、認證、檔案、搜尋、資料庫；以 esbuild 打包成 `dist/server`。
- `src/client`：Vite + React + BlockNote + Mantine 的 SPA，建置到 `dist/client`。
- `tests`：vitest；`scripts/check-app.mjs`：對運行中容器的靜態檢查。
