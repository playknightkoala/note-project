# 手機離線筆記

一般筆記可在 iOS Safari 與 Android Chrome 離線開啟、新增、編輯標題與內文。這是網站的 PWA 功能，不必安裝原生 App；本機內容以 BlockNote JSON 保存，連線後同步至原本的 Notes 伺服器。

## 第一次準備

1. 用手機連上 **HTTPS 網址**並登入。`http://192.168…` 不支援離線介面；電腦的 localhost／127.0.0.1 是瀏覽器提供的開發例外。
2. 等待「離線與同步」顯示「離線介面已準備完成」。在 Safari／Chrome 的分享或選單中加入主畫面，可像 App 一樣開啟。
3. 登入並連線開啟網站後，會自動下載全部一般筆記的標題與內文。等待畫面顯示綠色「離線筆記已同步完成」與最近完整同步時間，不必手動逐篇下載；也可按「離線與同步 → 立即同步」檢查更新。
4. 在預計使用的主畫面入口再確認一次下載狀態；不要假設瀏覽器分頁與主畫面入口一定共用同一份裝置資料。

尚未下載的筆記，離線時會提示連線後再開啟；第一次從未造訪過網站，也無法離線下載介面。伺服器停機時同樣只能讀取本機已有的內容。

## 保存與同步

- 「編輯中／儲存中」：目前輸入尚未確認保存；離開前請等待。
- 「已存此裝置，待同步」：已成功寫入手機本機，重新開啟仍可讀取；其他裝置尚未取得。
- 「已同步」：目前內容已保存於伺服器。
- 上方綠色「離線筆記已同步完成」：本次檢查中所有一般筆記的標題與內文已下載，且沒有待上傳草稿。這不代表附件已全部下載；最近完整同步時間是上次成功檢查的時間，不保證其他裝置此後沒有新增修改。
- 「正在同步離線筆記／同步尚未完成／部分筆記需要處理」：仍在傳輸、連線或儲存失敗，或有衝突待處理，不會提前宣稱全部完成。
- 「尚未儲存，請勿關閉／儲存失敗」：不要清除資料或關閉，先檢查訊息並重試。

恢復連線、切回網站或重新開啟時會自動上傳與下載；網站可見時每分鐘比對版本、頁面資訊與麵包屑，只下載新增或有變動的筆記，包含尚未開啟過的筆記。遠端刪除的乾淨副本會標記為不可離線開啟；有待同步內容則保留供救援，不自動丟棄。待上傳內容每 15 秒檢查一次，網路失敗時逐步延後重試（最長 5 分鐘，伺服器要求更久時遵守）；「立即同步」可主動重試。登入過期時須先重新登入同一帳號，草稿仍保留。手機必須能連到原伺服器；只有區網位址時，離開家中 Wi-Fi 不代表一定能同步。

**iOS 和 Android 的共同驗收目標是開啟時自動同步。** 不保證鎖屏、切背景或完全關閉後立即同步，也沒有依賴 Background Sync。

## 衝突與救援

手機與另一裝置修改同篇筆記時，不會偷偷覆蓋，也不會自動合併文字。伺服器以版本與標題基準判斷衝突，回覆 409 後停止該篇自動上傳，本機草稿保留；其他沒有衝突的筆記繼續更新。開啟該筆記後可先「匯出此處草稿」，再選擇：

- **載入最新版本**：確認後捨棄這裡的修改，採用最新線上內容；需要保留的草稿應先匯出。
- **以我的內容覆蓋**：確認後，以目前標題與內文覆蓋線上內容；會先取得最新基準再寫入，被覆蓋內容會保存在頁面歷史。若取得基準後線上版本或標題再次變更，仍會再報衝突，不會強行寫入。

同一裝置不同分頁的草稿也會比對 revision；處理衝突期間若另一分頁又改動，不會靜默捨棄該分頁的新草稿。

同步清單會保留所有尚未同步的筆記，包括伺服器已刪除、拒絕寫入或內容驗證失敗的項目。可以匯出本機草稿 JSON，再決定如何處理；匯出僅供救援保存，目前沒有自動重新匯入功能。「捨棄本機草稿」須確認，會刪除此裝置該筆記的副本與未同步修改，不影響伺服器版本。

有待同步內容時會阻止登出。請先完成同步，或匯出並明確捨棄後再登出；登出成功後會清除此裝置的筆記與附件快取。不要在共用手機上保留登入與離線資料。

## 本次支援範圍

- 離線可修改一般筆記的標題、區塊內文與文字格式，支援根頁及已下載一般筆記底下的新子頁。
- 資料庫視圖／結構、資料列、留言與反應、搜尋、最愛、搬移、垃圾桶、圖示／封面及新附件上傳需要連線。未將這些操作假裝保存到離線佇列。
- 自動下載涵蓋一般筆記標題與內文，不限制為 100 篇。附件須另外在連線時開啟，才由已啟用的 Service Worker 快取；預設每裝置、每帳號總計 **500 MB**，可在「離線與同步」設為 100–10,000 MB，不再限制為每檔 20 MB 或 100 個。超出總容量會移除較早的附件快取，單檔超過設定總容量則只在線上提供；伺服器原檔不受影響。降低容量後會通知目前啟用的 Service Worker 清理超額快取。外部網站連結及外部圖片不納入離線下載。
- 伺服器附件上傳預設上限 **90 MB**，可用 `NOTES_MAX_UPLOAD_MB` 調整；離線設定畫面顯示伺服器回報的實際上限。此設定與手機的離線快取容量分開。專案容量數值以 1024 × 1024 bytes 計算；90 MB 可替 Cloudflare 的 100 MB 請求上限留餘裕，實際仍受代理設定約束。
- 本機儲存有瀏覽器與裝置容量限制；應用會嘗試申請持久儲存，但瀏覽器可拒絕。私人瀏覽不適合作為離線筆記的保存位置。手動清除網站資料、移除網站 App 或儲存空間不足，可能移除未同步內容；看到儲存錯誤時先保留編輯畫面並救援。
- 左下角顯示此分頁正在使用的介面版本，點擊可檢查更新。伺服器部署新版後，網站開啟、切回前景、恢復連線與可見時每分鐘會檢查；偵測到較新版會自動顯示更新資訊 Modal。可按「立即更新」讓新版介面接手並重新載入目前分頁，或選「稍後更新」繼續使用，左下角保留「有新版」入口。
- 更新前會保存筆記標題與內文，已在此裝置保存但尚未同步的筆記、登入與附件快取會保留；若有無法保存的修改、未送出留言、未完成表單或附件上傳，會提示先處理，再允許更新。失敗會留在目前介面供重試，不清除 IndexedDB 或附件快取。
- 其他分頁收到新版提醒後仍保留目前內容，不會被另一分頁的更新動作重新載入；它們使用的舊介面資源保留到所有開啟的分頁完成更新。沒有按「立即更新」時，新的 Service Worker 仍可在所有舊分頁關閉後自然接手。
- **首次從 1.0.5 或更早版升級到 1.0.6 時，仍需先連線重新載入一次**，讓更新提示功能載入；較舊介面原本沒有這項功能。之後部署的新版才會自動提醒。手機需要 HTTPS；不保證關閉網站後能顯示更新提醒。
