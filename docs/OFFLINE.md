# 手機離線筆記

一般筆記可在 iOS Safari 與 Android Chrome 離線開啟、新增、編輯標題與內文。這是網站的 PWA 功能，不必安裝原生 App；本機內容以 BlockNote JSON 保存，連線後同步至原本的 Notes 伺服器。

## 第一次準備

1. 用手機連上 **HTTPS 網址**並登入。`http://192.168…` 不支援離線介面；電腦的 localhost／127.0.0.1 是瀏覽器提供的開發例外。
2. 等待「離線與同步」顯示「離線介面已準備完成」。在 Safari／Chrome 的分享或選單中加入主畫面，可像 App 一樣開啟。
3. 連線開啟過的一般筆記會自動下載。若想準備完整內文，在「離線與同步」按「下載全部一般筆記」，等候完成。
4. 在預計使用的主畫面入口再確認一次下載狀態；不要假設瀏覽器分頁與主畫面入口一定共用同一份裝置資料。

尚未下載的筆記，離線時會提示連線後再開啟；第一次從未造訪過網站，也無法離線下載介面。伺服器停機時同樣只能讀取本機已有的內容。

## 保存與同步

- 「編輯中／儲存中」：目前輸入尚未確認保存；離開前請等待。
- 「已存此裝置，待同步」：已成功寫入手機本機，重新開啟仍可讀取；其他裝置尚未取得。
- 「已同步」：目前內容已保存於伺服器。
- 「尚未儲存，請勿關閉／儲存失敗」：不要清除資料或關閉，先檢查訊息並重試。

恢復連線、切回網站或重新開啟時會自動同步；開著頁面時每 15 秒也會重試。登入過期時須先重新登入同一帳號，草稿仍保留。手機必須能連到原伺服器；只有區網位址時，離開家中 Wi-Fi 不代表一定能同步。

**iOS 和 Android 的共同驗收目標是開啟時自動同步。** 不保證鎖屏、切背景或完全關閉後立即同步，也沒有依賴 Background Sync。

## 衝突與救援

手機與另一裝置修改同篇筆記時，不會偷偷覆蓋。畫面提供載入最新版本或以自己的內容覆蓋；覆蓋前仍檢查版本，被覆蓋內容會保存在頁面歷史。

同步清單會保留所有尚未同步的筆記，包括伺服器已刪除、拒絕寫入或內容驗證失敗的項目。可以匯出本機草稿 JSON，再決定如何處理；匯出僅供救援保存，目前沒有自動重新匯入功能。「捨棄本機草稿」須確認，會刪除此裝置該筆記的副本與未同步修改，不影響伺服器版本。

有待同步內容時會阻止登出。請先完成同步，或匯出並明確捨棄後再登出；登出成功後會清除此裝置的筆記與附件快取。不要在共用手機上保留登入與離線資料。

## 本次支援範圍

- 離線可修改一般筆記的標題、區塊內文與文字格式，支援根頁及已下載一般筆記底下的新子頁。
- 資料庫視圖／結構、資料列、留言與反應、搜尋、最愛、搬移、垃圾桶、圖示／封面及新附件上傳需要連線。未將這些操作假裝保存到離線佇列。
- 「下載全部一般筆記」下載標題與內文。附件須另外在連線時開啟，才由已啟用的 Service Worker 快取；每檔最多 20 MB，每帳號最近 100 檔，超限會移除較早快取。外部網站連結及外部圖片不納入離線下載。
- 本機儲存有瀏覽器與裝置容量限制；應用會嘗試申請持久儲存，但瀏覽器可拒絕。私人瀏覽不適合作為離線筆記的保存位置。手動清除網站資料、移除網站 App 或儲存空間不足，可能移除未同步內容；看到儲存錯誤時先保留編輯畫面並救援。
- 程式更新完成後，新 Service Worker 會等待舊分頁關閉再接手，避免編輯中突然切換版本。首次使用此功能或更新後，先連線確認「離線介面已準備完成」。
