# 手機離線筆記

一般筆記、資料庫、留言與附件都可在 iOS Safari 與 Android Chrome 離線使用：開啟與編輯筆記、開啟資料庫並修改資料列、留言與加表情、在筆記中加入圖片與檔案。這是網站的 PWA 功能，不必安裝原生 App；本機內容以 BlockNote JSON 保存，連線後同步至原本的 Notes 伺服器。資料庫、留言與附件的細節見下方「資料庫、留言與附件」。

## 第一次準備

1. 用手機連上 **HTTPS 網址**並登入。`http://192.168…` 不支援離線介面；電腦的 localhost／127.0.0.1 是瀏覽器提供的開發例外。
2. 等待「離線與同步」顯示「離線介面已準備完成」。在 Safari／Chrome 的分享或選單中加入主畫面，可像 App 一樣開啟。
3. 登入並連線開啟網站後，會自動下載全部一般筆記的標題與內文，以及所有資料庫（結構、視圖、資料列與列內文）與留言。等待畫面顯示綠色「離線筆記已同步完成」與最近完整同步時間，不必手動逐篇下載；也可按「離線與同步 → 立即同步」檢查更新。
4. 在預計使用的主畫面入口再確認一次下載狀態；不要假設瀏覽器分頁與主畫面入口一定共用同一份裝置資料。

尚未下載的筆記，離線時會提示連線後再開啟；第一次從未造訪過網站，也無法離線下載介面。伺服器停機時同樣只能讀取本機已有的內容。

## 保存與同步

- 「編輯中／儲存中」：目前輸入尚未確認保存；離開前請等待。輸入法組字中離開頁面、切到背景或關閉分頁時，會直接保存已輸入的內容（含尚未選字的部分）；連續組字最久 5 秒也會保存一次。
- 「已存此裝置，待同步」：已成功寫入手機本機，重新開啟仍可讀取；其他裝置尚未取得。
- 「已同步」：目前內容已保存於伺服器。
- 上方綠色「離線筆記已同步完成」：本次檢查中所有一般筆記、資料庫與留言已下載，且沒有待上傳的草稿、資料庫或留言修改，也沒有待上傳的附件。這不代表既有附件已全部下載；最近完整同步時間是上次成功檢查的時間，不保證其他裝置此後沒有新增修改。
- 「正在同步離線筆記／同步尚未完成／部分筆記需要處理」：仍在傳輸、連線或儲存失敗，或有衝突待處理，不會提前宣稱全部完成。
- 「尚未儲存，請勿關閉／儲存失敗」：不要清除資料或關閉，先檢查訊息並重試。

恢復連線、切回網站或重新開啟時會自動上傳與下載；網站可見時每分鐘比對版本、頁面資訊與麵包屑，只下載新增或有變動的筆記，包含尚未開啟過的筆記。遠端刪除的乾淨副本會標記為不可離線開啟，並清除此裝置上的內文；有待同步內容則保留供救援，不自動丟棄。只改圖示、封面、最愛、搬移或上層頁面名稱不算內文變更，不會重新載入開啟中的編輯器。待上傳內容每 15 秒檢查一次，網路失敗時逐步延後重試（最長 5 分鐘，伺服器要求更久時遵守）；「立即同步」可主動重試。登入過期時須先重新登入同一帳號，草稿仍保留。被伺服器拒絕的草稿（例如內容超過 2 MB）修改後按「重試同步」，會送出修改後的內容。手機必須能連到原伺服器；只有區網位址時，離開家中 Wi-Fi 不代表一定能同步。

**iOS 和 Android 的共同驗收目標是開啟時自動同步。** 不保證鎖屏、切背景或完全關閉後立即同步，也沒有依賴 Background Sync。

## 衝突與救援

手機與另一裝置修改同篇筆記時，不會偷偷覆蓋，也不會自動合併文字。伺服器以版本與標題基準判斷衝突，回覆 409 後停止該篇自動上傳，本機草稿保留；其他沒有衝突的筆記繼續更新。上傳成功但回應在半路遺失時，裝置會重送同一筆操作；若這段期間別人（共用頁面的成員或擁有者）已儲存新版，而你又繼續寫了新內容，同樣會列為衝突，不會把你的新內容直接蓋在對方的版本上。開啟該筆記後可先「匯出此處草稿」，再選擇：

- **載入最新版本**：確認後捨棄這裡的修改，採用最新線上內容；需要保留的草稿應先匯出。
- **以我的內容覆蓋**：確認後，以目前標題與內文覆蓋線上內容；會先取得最新基準再寫入，被覆蓋內容會保存在頁面歷史。若取得基準後線上版本或標題再次變更，仍會再報衝突，不會強行寫入。

衝突尚未處理時繼續輸入，一般筆記與資料列頁面的內文仍會存在此裝置（不上傳），離開頁面再回來仍在。此裝置沒有該頁面副本（例如本機儲存無法使用）而衝突中有未保存的修改時，離開前會先詢問是否放棄。

同一裝置不同分頁的草稿也會比對 revision；處理衝突期間若另一分頁又改動，不會靜默捨棄該分頁的新草稿。這種情況下這個分頁的修改無法存入裝置，離開前同樣會先詢問。

還原頁面歷史前會先保存並同步目前的修改，讓它們進入頁面歷史；仍有未同步或衝突中的內容時不允許還原。

同步清單會保留所有尚未同步的筆記、資料庫與留言修改及待上傳附件，包括伺服器已刪除、拒絕寫入或內容驗證失敗的項目。可以匯出本機草稿 JSON，再決定如何處理；匯出僅供救援保存，目前沒有自動重新匯入功能。「捨棄本機草稿」須確認，會刪除此裝置該筆記的副本與未同步修改，不影響伺服器版本。

有待同步內容（筆記草稿、資料庫或留言修改、待上傳附件）時會阻止登出。請先完成同步，或匯出並明確捨棄後再登出；登出成功後會清除此裝置的筆記與附件快取。不要在共用手機上保留登入與離線資料。

同一個瀏覽器換帳號時：另一個帳號登入後，前一個帳號已同步的筆記副本與附件快取會從裝置移除；前一個帳號尚未同步的草稿、資料庫與留言修改、待上傳附件不會被別人的登入或登出刪除，原帳號重新登入後仍可同步或匯出。這些草稿在此期間仍存在裝置上，所以共用裝置請先同步再交給別人。

## 資料庫、留言與附件（1.0.8 起）

這三類修改不是整篇草稿，而是一項一項的小操作（改一格、加一列、加一則留言）。連線時直接送出，結果與錯誤當場顯示；離線或送出時斷線，則存入此裝置的待同步清單，畫面以「下載的副本＋待同步的修改」顯示，並標示「目前顯示此裝置上的副本」。恢復連線後依原順序送出；每項操作帶有固定識別碼，伺服器只會執行一次，回應遺失後重送不會重複新增。

**資料庫**

- 離線可開啟資料庫的所有視圖（表格、清單、看板），排序與篩選在裝置上計算，結果與線上相同。
- 離線可修改儲存格與列名稱、新增資料列、開啟資料列頁面並編輯內文與屬性；也可新增、修改、刪除欄位與視圖。此裝置新增的資料列在同步前就能開啟與編輯。
- **逐格比對**：每項修改記錄該格在開始編輯時的值。伺服器上該格仍是那個值就套用；兩邊改的是不同欄位會自動合併；只有同一格（或列名稱）在兩邊都被修改才算衝突，訊息會指出欄位名稱。
- **結構修改比對版本**：欄位與視圖的修改以資料庫結構版本比對，其他裝置已改過結構就算衝突。此裝置連續做的多項結構修改會依序接續，不互相衝突。
- 衝突或被拒絕（例如選項不存在、欄位已被刪除、超過 5,000 列）的修改留在「離線與同步」清單並顯示原因；同一資料庫後續的修改會等它處理完才送出，其他資料庫與筆記不受影響。可選「重試同步」、「以我的修改覆蓋」（僅衝突時提供，確認後套用到最新資料）、「匯出」或「捨棄」。系統不會自動覆蓋另一台裝置的值。捨棄「新增資料列」時，該列後續的修改、留言與此裝置上的列內文一併移除（確認視窗會說明，「匯出」會包含列內文）。
- 移至垃圾桶、新增資料庫本身仍需連線。

**留言與表情反應**

- 離線可對選取文字新增討論、回覆、加上或取消表情、標示已解決／重新開啟、刪除整則討論；黃色標記立即顯示，討論清單會標示「目前顯示此裝置上的留言」。
- 留言只會往後附加、表情是明確的「加上／取消」、已解決以最後一次為準，因此多裝置之間不會跳衝突視窗：另一台裝置先回覆，這裡離線寫的回覆仍會接在後面。留言時間採寫下的時間（不晚於伺服器時間）。
- 刪除整則討論會連同其中的留言一起刪除，因此會比對留言數：討論若有此裝置還沒看過的新留言，刪除不會執行（連線時當場提示並重新載入；離線排入的刪除則列為衝突，確認後才刪除）。
- 回覆的討論若已在其他裝置被刪除，該則回覆會列在待同步清單並說明原因，不會自動重建討論。
- 離線新增的筆記上的留言，會等該筆記上傳後才送出。

**附件**

- 離線在筆記或資料列內文中加入的圖片與檔案先存在此裝置，以正式網址顯示（由離線介面提供），連線後先上傳附件、再同步引用它的筆記，其他裝置不會看到缺檔的筆記。附件若被伺服器拒絕（例如超過上限），引用它的筆記會留在此裝置等待，直到重試成功或捨棄該附件。
- 待上傳附件不計入附件快取上限，也不會被自動清除；上傳後轉入一般附件快取，離線仍可開啟。「離線與同步」會列出每個待上傳附件，可下載此裝置上的副本、重試或捨棄。
- 檔案類型判定與伺服器相同：只有實際內容是 PNG／JPEG／GIF／WebP 的檔案會直接顯示，其他一律以附件下載（含沙箱標頭）。空檔案與超過伺服器上限的檔案在加入時就會拒絕。
- 需要已啟用且已更新到 1.0.8 的離線介面（HTTPS 或 localhost）；尚未啟用或仍是舊版離線介面時，離線加入附件會顯示錯誤而不是假裝成功。封面圖片仍需連線。
- 待上傳的大檔只存在此裝置：清除網站資料、移除網站 App 或瀏覽器回收空間會讓它遺失，風險高於文字草稿。瀏覽器已清掉內容時，清單會明確顯示「附件內容已遺失」。

## 別人分享的筆記（1.1.0 起）

別人以帳號分享給你的頁面、資料庫與留言會和自己的筆記一起下載，離線可從側欄「與我共用」開啟。權限說明見 [SHARING.md](SHARING.md)。

- 「唯讀」的頁面離線只能閱讀與留言；「可編輯」的頁面可離線修改內文、標題、儲存格與新增資料列，連線後同步。
- 與擁有者同時修改同一頁時，後同步的一方會看到版本衝突，處理方式與自己的筆記相同。
- 離線時不能在別人的頁面底下新增子頁面；資料庫的欄位與視圖只有擁有者能改。
- 離線期間被改為唯讀或被移除時，尚未同步的修改不會寫入對方的頁面，會留在「離線與同步」並顯示原因，可匯出或捨棄；分享結束後，裝置上乾淨的副本會在下次同步時清除。
- 公開連結（`/s/…`）不提供離線：訪客的瀏覽器不會安裝離線介面。

## 支援範圍

- 離線可修改一般筆記的標題、區塊內文與文字格式，支援根頁及已下載一般筆記底下的新子頁；資料庫、留言與附件如上節。
- 搜尋、頁面歷史、最愛、搬移、垃圾桶、圖示／封面、新增資料庫需要連線。未將這些操作假裝保存到離線佇列。
- 自動下載涵蓋一般筆記標題與內文（不限制為 100 篇）、所有資料庫與留言。資料庫有變動時會重新下載整個資料庫的結構與資料列（上限 5,000 列），列內文只下載有變動的頁面；列數很多的資料庫每次變動的下載量較大。既有附件須另外在連線時開啟，才由已啟用的 Service Worker 快取；預設每裝置、每帳號總計 **500 MB**，可在「離線與同步」設為 100–10,000 MB，不再限制為每檔 20 MB 或 100 個。超出總容量會移除較早的附件快取，單檔超過設定總容量則只在線上提供；伺服器原檔不受影響。降低容量後會通知目前啟用的 Service Worker 清理超額快取。外部網站連結及外部圖片不納入離線下載。
- 伺服器附件上傳預設上限 **90 MB**，可用 `NOTES_MAX_UPLOAD_MB` 調整；離線設定畫面顯示伺服器回報的實際上限。此設定與手機的離線快取容量分開。專案容量數值以 1024 × 1024 bytes 計算；90 MB 可替 Cloudflare 的 100 MB 請求上限留餘裕，實際仍受代理設定約束。
- 本機儲存有瀏覽器與裝置容量限制；應用會嘗試申請持久儲存，但瀏覽器可拒絕。私人瀏覽不適合作為離線筆記的保存位置。手動清除網站資料、移除網站 App 或儲存空間不足，可能移除未同步內容；看到儲存錯誤時先保留編輯畫面並救援。
- 左下角顯示此分頁正在使用的介面版本，點擊可檢查更新。伺服器部署新版後，網站開啟、切回前景、恢復連線與可見時每分鐘會檢查；偵測到較新版會自動顯示更新資訊 Modal。可按「立即更新」讓新版介面接手並重新載入目前分頁，或選「稍後更新」繼續使用，左下角保留「有新版」入口。
- 更新前會保存筆記標題與內文，已在此裝置保存但尚未同步的筆記、待同步的資料庫與留言修改、待上傳附件、登入與附件快取會保留；若有無法保存的修改、未送出留言、未完成表單或附件上傳，會提示先處理，再允許更新。失敗會留在目前介面供重試，不清除 IndexedDB 或附件快取。
- 其他分頁收到新版提醒後仍保留目前內容，不會被另一分頁的更新動作重新載入；它們使用的舊介面資源保留到所有開啟的分頁完成更新。沒有按「立即更新」時，新的 Service Worker 仍可在所有舊分頁關閉後自然接手。
- **首次從 1.0.5 或更早版升級到 1.0.6 時，仍需先連線重新載入一次**，讓更新提示功能載入；較舊介面原本沒有這項功能。之後部署的新版才會自動提醒。手機需要 HTTPS；不保證關閉網站後能顯示更新提醒。
