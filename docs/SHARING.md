# 分享筆記（1.1.0 起；「知道連結的本站帳號」自 1.1.1，1.1.2 起為公開連結的設定）

每個帳號的筆記預設只有自己看得到。分享有兩種方式，可以同時使用，由頁面的擁有者設定：

| 方式 | 對象 | 能做什麼 |
|---|---|---|
| **公開連結** | 任何知道網址的人，不需登入 | 只能閱讀；看不到留言與表情反應 |
| **公開連結＋登入的本站帳號** | 登入本站後開啟同一個公開連結的帳號（要另外設定才有） | 依設定為「唯讀」或「可編輯」，權限同下一列 |
| **站內帳號** | 以 email 個別指定的本站帳號 | 「唯讀」：閱讀、留言、加表情。「可編輯」：另外可修改內文、標題、資料列，並加入附件 |

## 開始分享

1. 開啟頁面，按頂端的「分享」（或頁面「…」選單、側欄頁面選單的「分享」）。資料庫也可以分享；資料列要透過它所屬的資料庫分享。
2. 選擇**開放範圍**：
   - **只有此頁面**：只開放這一頁。頁面內連到其他頁面的連結，對方無法開啟。
   - **此頁面與子頁面**：連同底下所有子頁面；底下的資料庫不開放。
   - **此頁面、子頁面與資料庫**：底下的資料庫與資料列也開放。
   - 分享的頁面本身是資料庫時，資料列一定一起開放。
   - 公開連結與成員共用同一個範圍。之後新增或搬進範圍內的頁面也會自動開放。
3. 需要公開連結就打開「公開連結」開關，複製網址給對方。每個分享只有這一個連結。
   - 打開後，開關下方出現「**知道連結的本站帳號**」：決定登入本站的帳號開啟這個連結時可以做什麼。預設是「與未登入相同（只能閱讀）」；可改為「知道連結的人皆可唯讀」（另外可以留言與加表情）或「知道連結的人皆可編輯」。
   - 沒有登入的人不受這個設定影響，用同一個連結一律只能閱讀。
   - 公開連結關閉時沒有這個選項；要讓本站帳號不靠公開連結使用，請用下一步個別指定。
4. 要與特定的本站帳號共用，輸入對方註冊時使用的 email、選擇「唯讀」或「可編輯」，按「加入」。之後可以在同一個視窗改權限或移除。對方不需要連結。同一個帳號也透過公開連結進來時，取權限較高者。

已分享的頁面在側欄有共用圖示，頂端按鈕顯示「已分享」。「設定 → 分享」列出你開放給其他人的所有頁面，可以直接管理或停止分享。如果頁面是因為上層頁面的分享而被開放，分享視窗會提醒。

## 各角色可以做的事

| | 擁有者 | 可編輯 | 唯讀 | 公開連結 |
|---|---|---|---|---|
| 閱讀內文、圖片與附件 | ✓ | ✓ | ✓ | ✓ |
| 留言、回覆、表情、標示已解決 | ✓ | ✓ | ✓ | — |
| 修改內文、一般頁面的標題、加入附件 | ✓ | ✓ | — | — |
| 修改儲存格與資料列名稱、新增資料列、編輯列內文 | ✓ | ✓ | — | — |
| 新增子頁面或資料庫、修改欄位與視圖 | ✓ | — | — | — |
| 圖示、封面、全寬、最愛、搬移、複製頁面 | ✓ | — | — | — |
| 頁面歷史、移至垃圾桶 | ✓ | — | — | — |
| 設定分享 | ✓ | — | — | — |

- 刪除整則討論：擁有者，或發起那則討論的人。
- 成員可以排序、篩選資料庫，但只影響自己的畫面，不會改到擁有者的視圖。
- 沒有即時協作。兩個人同時修改同一頁時，後存的人會看到「此頁面已在其他地方更新」，與自己在兩台裝置上編輯的處理方式相同（載入最新版本，或以自己的內容覆蓋）。
- 成員修改內文時，被取代的內容會立即留一份在頁面歷史，擁有者可以還原。擁有者寫的版本與成員寫的版本分開保留（各 100 份），成員存再多次也不會把擁有者的版本擠掉。

## 對方怎麼看到

- **站內帳號**：登入後，側欄「與我共用」列出別人分享的頁面與範圍內的子頁面，頁面上方標示擁有者與權限。不會收到通知。不想再看到，可在該項目的選單選「移除這項共用」。
- **公開連結**：網址是 `https://你的網域/s/…`。頁面只有閱讀功能，範圍內有多個頁面時左側顯示清單。連到範圍外頁面的連結會顯示為「無法存取的頁面」。
- **登入的本站帳號開啟公開連結**：擁有者有設定「皆可唯讀」或「皆可編輯」時，會直接進入應用程式內的那個頁面（網址變成 `/p/…`），依設定的權限使用。開啟過一次後，這個頁面同樣列在「與我共用」並下載到裝置；擁有者在分享視窗看得到有哪些帳號開啟過。自行移除後就不能再開啟，重新開啟公開連結才會回來。只知道 `/p/…` 的頁面網址而沒有開啟過公開連結，不會有任何權限。擁有者沒有設定時，登入的帳號看到的和未登入的人一樣是唯讀頁面；擁有者自己與個別指定的成員開啟公開連結，則一律進入自己原本就能使用的頁面。

共用的筆記不會出現在對方的搜尋結果、最愛或垃圾桶。

## 留言

- 留言與每則回覆都顯示作者；表情反應每個人各自計算，取消自己的不影響別人。
- 唯讀成員選取文字後會出現「留言」與表情按鈕。唯讀成員的討論完全不會改動頁面（內文與版本都不變）：黃色標示是每個人的畫面依「被引用的文字」在原本的段落裡找出來的。那段文字之後被改掉時，討論仍會出現在「留言與反應」清單，只是不再標示；同一段落有重複的相同文字時，標示的是第一處。
- 標示為已解決會讓所有人都看不到標示，所以只有擁有者、可編輯的成員與發起那則討論的人可以做。
- 在別人的頁面上，每人每頁最多發起 100 則討論，每則討論每人最多 20 個表情。

## 頁面提及

共用的頁面裡若提及（`@`）了沒有分享給對方的頁面，成員只會看到「無法存取這個頁面」的標記，看不到那個頁面的標題。成員編輯並儲存這份內文後，擁有者看到的提及與標題不變。公開連結的訪客看到的是固定文字「無法存取的頁面」。

## 附件

- 可編輯的成員加入的圖片與檔案歸頁面擁有者所有，成員之後被移除也不會讓頁面缺圖。
- 成員與公開連結的訪客只能讀取「看得到的頁面」所顯示的檔案（內文或封面），讀不到擁有者的其他檔案。

## 離線

別人分享給你的筆記、資料庫與留言會和自己的一起下載到裝置，離線可以閱讀；可編輯的成員可以離線修改，連線後同步。詳見 [OFFLINE.md](OFFLINE.md)。

- 離線時不能在別人的頁面底下新增子頁面。
- 離線期間被降為唯讀或被移除時，尚未同步的修改不會寫入對方的頁面，會留在「離線與同步」清單並顯示原因，可以匯出或捨棄。
- 權限被調整（例如由可編輯改為唯讀）後，裝置在下次同步時就會得知，包含資料庫與資料列；不必等內容有變動。

## 停止分享

- 關閉「公開連結」開關後，那個網址永久失效，「知道連結的本站帳號」的設定與透過連結進來的帳號也一併結束；再次開啟會產生新的網址，帳號的設定要重新選。
- 把頁面移至垃圾桶會一併關閉它與底下頁面的公開連結（連同上述設定）；還原後不會自動恢復，需要重新開啟。成員名單會保留，頁面還原後成員即可再開啟。
- 移除成員或按「停止分享」後，對方立即無法開啟；對方裝置上的副本會在下次同步時清除。
- 把「知道連結的本站帳號」改回「與未登入相同（只能閱讀）」後，透過連結進來的帳號立即失去權限，只能像其他人一樣閱讀公開頁面（個別加入的成員不受影響）；之後重新設定時，不會記得先前開啟過的帳號。
- 擁有者的帳號被停用時，所有分享（含公開連結）都無法開啟。

## 注意事項

- **公開連結就是鑰匙**：任何拿到網址的人都能閱讀範圍內的內容，包含之後加進範圍的頁面。網址不會出現在搜尋引擎（頁面與 API 都標示不索引），但可能留在瀏覽器紀錄、聊天紀錄或反向代理的存取紀錄中。懷疑外流時，關閉後重新開啟即可換網址。
- **「知道連結的人皆可編輯」的範圍很大**：本站任何拿到公開連結的帳號都能修改這個頁面與範圍內的頁面。被取代的內容會留在頁面歷史，擁有者可以還原。懷疑連結外流時，關閉公開連結再重新開啟即可換網址，先前透過連結進來的帳號也會全部失效。
- 登入的帳號開啟公開連結就會被記為「開啟過」並把頁面加入自己的「與我共用」；任何人都可以把連結傳給別人，請只開啟你信任的連結。
- 以 email 加入成員時，系統必須回答「找不到這個帳號」，因此本站的使用者可以藉此得知某個 email 是否已註冊；每個帳號每小時最多嘗試 30 次。
- 成員看得到共用頁面內「連到其他頁面」的連結標題（連結建立時的標題）。只有公開連結會把範圍外的連結替換掉。
- 可編輯的成員如果知道擁有者某個檔案的識別碼，可以把它放進共用頁面而使它可被共用對象讀取；識別碼是隨機的，無法猜測。
- 公開連結頁面與一般頁面使用同一份前端，訪客第一次開啟需要下載完整介面。
