# 1.0.7 — 資安強化與保存可靠性修正

對 1.0.6 做整體 code review 與資安檢查後的修正版。沒有新增資料庫 migration，沒有調整任何依賴版本。

## 保存與離線

- 輸入法組字中離開頁面、切到背景或關閉分頁時，會直接保存已輸入的內容；連續組字最久 5 秒保存一次。先前這種情況下，上次保存之後輸入的文字會遺失且沒有提示。
- 資料列頁面不再把自己的自動保存當成其他地方的更新，不會再跳出衝突提示或重新載入編輯器。
- 衝突尚未處理時繼續輸入，一般筆記的內容仍會存在此裝置；無法存入時（資料列，或另一個分頁有較新的草稿）離開頁面前會先詢問。
- 只改圖示、封面、最愛、搬移或上層頁面名稱，不再重新載入開啟中的編輯器。
- 被伺服器拒絕的離線草稿（例如內容超過 2 MB）修改後按「重試同步」，會送出修改後的內容。
- 還原頁面歷史前會先保存並同步目前的修改；仍有未同步或衝突中的內容時不允許還原。
- 標題輸入後立即離開仍會送出；斜線選單的「子頁面」可離線建立，失敗時顯示錯誤。
- 線上已永久刪除的筆記，此裝置上的內文會一併清除。
- 同一個瀏覽器換帳號時：另一個帳號登入後，前一個帳號已同步的副本與附件快取會移除；前一個帳號尚未同步的草稿不會被別人的登入或登出刪除。

## 離線介面與附件

- 開著分頁時部署新版，舊的 Service Worker 不再刪除新版的離線快取；新版啟用時會補回缺少的介面檔。
- 附件先顯示再於背景存入離線快取，多個附件可同時下載，內容相同不重複下載或重寫。
- 不存在的 `/assets/*` 回 404，不再回應並快取成應用程式頁面。

## 資安

- 所有端點都有請求大小上限（帳號相關 64 KB、其他 JSON 8 MB、附件依 `NOTES_MAX_UPLOAD_MB`），未帶 `Content-Length` 的請求也在讀到上限時中止。先前未登入即可用超大請求耗用伺服器記憶體。
- 速率限制的來源位址改取 `X-Forwarded-For` 的最後一段，HTTPS overlay 的 nginx 改為覆寫該標頭。先前經 overlay 可用自填的標頭繞過限制。
- 登入限制改為：每個來源 15 分鐘 10 次；同一來源對同一帳號 5 次失敗後暫停 15 分鐘；同一帳號不分來源以 30 次為上限。別人從其他位址猜錯密碼不再鎖住帳號本人。
- 登入與註冊只接受同源請求；所有 JSON 端點要求 `Content-Type: application/json`。
- 註冊時先驗證邀請碼，沒有有效邀請碼的人無法探測哪些電子郵件已註冊。
- 每小時清除過期的 session；登入後的導向只接受站內路徑。

## 資料庫

- 修改單選／多選欄位的選項時，只移除指向已刪除選項的篩選，保留排序與其他篩選。
- 資料庫仍在垃圾桶時，不能單獨還原其中的資料列（請先還原資料庫）。

## 部署

- HTTPS overlay：nginx 改為串流轉送請求內容。先前超過約 16 MB 的附件經 overlay 上傳會回 500。
- 新增兩個選用設定（見 `.env.example` 與 [DEPLOY.md](../DEPLOY.md)）：
  - `NOTES_CLIENT_IP_HEADER`：代理以專用標頭提供訪客位址時指定。**經 Cloudflare（橘雲或 Tunnel）部署請設為 `cf-connecting-ip`**，否則所有訪客會共用同一個來源額度。
  - `NOTES_SETUP_TOKEN`：設定後，建立第一個（管理者）帳號必須輸入這個值。網站在你註冊前就能被別人連到時使用。
- 自行撰寫的腳本呼叫 API 時必須帶 `Content-Type: application/json`，否則會收到 415。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up -d --build --wait
```

使用 HTTPS overlay 時加上 `-f compose.yaml -f compose.https.yaml`；`docker/https.nginx.conf` 有變更，nginx 容器需要重新建立才會套用。伺服器部署後，開著的分頁會收到更新提示；只建立 GitHub Release 不會更新運行中的容器。

## 驗證與限制

- typecheck、lint、30 檔／198 項測試與正式建置通過；`npm audit --omit=dev` 0 個漏洞。
- 以獨立的容器（app 與 HTTPS overlay）實測請求大小上限、速率限制、登入來源檢查與大檔上傳下載。
- 沒有實際瀏覽器、實體手機或真實輸入法的驗收；輸入法、離開頁面的詢問與 Service Worker 行為以模擬環境的測試為準。
- 資料列頁面關閉分頁時，內容超過 64 KB 仍可能來不及送出（瀏覽器限制）。

實際命令與結果見 [VALIDATION.md](../VALIDATION.md)。
