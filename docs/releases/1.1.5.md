# 1.1.5 — 頁面頂列顯示最後編輯時間

頁面頂列原本只顯示保存狀態（「已同步」）。這一版在旁邊加上最後編輯時間，寫法與 Notion 相同。只改前端，沒有資料庫 migration，沒有調整任何依賴版本。

## 變更

- **顯示**：筆記頁（一般頁面與資料列頁面）的頂列，在「已同步」左邊顯示「已於 4 小時前 編輯」。保存狀態維持原樣，兩者並列。
- **文字**：不到 1 分鐘是「剛剛編輯」，之後是「已於 N 分鐘前／小時前／天前 編輯」，滿 7 天改顯示日期（例如「已於 11月3日 編輯」，不同年會加上年份）。滑鼠停留顯示完整時間。
- **更新**：頁面開著時每 30 秒自動重算。在這裡修改內文或標題會立刻變成「剛剛編輯」；別人或其他分頁的修改，在載入新內容時一併更新。
- **手機**：頂列放不下，改列在頁面選單（⋯）最底部。

## 範圍與限制

- 時間取自頁面的更新時間。除了內文與標題，改圖示、封面、全寬、搬移頁面、加入或移除最愛也會讓它變新。
- 資料庫頁面不顯示：資料列各自編輯，資料庫頁面自己的時間不反映資料列的修改。公開連結頁也不顯示。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up -d --build --wait
```

沒有 migration。已開啟的分頁會出現新版提示，更新後即可使用。
