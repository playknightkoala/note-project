# 1.1.11 — 幣值換算與欄位加總

原本的「費用試算」改為「幣值換算」欄位與「欄位加總」功能。原先手填的金額仍可在表格中使用。

- **幣值換算**　從「新增屬性」選擇「幣值換算」，指定新台幣和日圓，再填寫任一方向的匯率，另一方向會自動帶出。設定完成後，每格可輸入任一幣別的金額並即時查看換算結果。
- **欄位加總**　在表格工具列點「欄位加總」，勾選數字或金額欄位後儲存。合計涵蓋目前篩選條件下的所有資料列，並顯示在最後一筆資料下方。點表格下方的「新增頁面」時，新資料會出現在合計上方。

## 升級

使用 Docker Compose 部署時，更新至此版本後執行 `docker compose up --build --wait`。介面偵測到新版後會先保存修改，再提示「立即更新」。
