# 1.0.5 — 自動下載更新與離線同步狀態

- 登入並連線開啟、恢復連線與切回網站時，自動下載全部一般筆記的新增與變更；網站可見時每分鐘比對，不必反覆手動下載。
- 上傳與下載皆完成且沒有待處理草稿後，顯示「離線筆記已同步完成」與最近完整同步時間。失敗、傳輸中與衝突各有明確狀態，連線失敗會延後重試。
- 附件上傳預設提高為 90 MB；既有 `.env` 若明確設定舊值仍需調整。離線附件改採預設 500 MB 總容量，可在「離線與同步」調整至 100–10,000 MB，不再採用 20 MB／檔或 100 個的限制。
- 衝突保留本機草稿，可匯出目前編輯內容，確認後選擇載入最新版本或以本機內容覆蓋；覆蓋前的線上內容保留在頁面歷史。覆蓋仍比對版本與標題，處理期間另一分頁變更草稿也會拒絕靜默取代。
- 附件仍需連線開啟才會快取；完成提示只保證本次檢查的筆記標題與內文。手機完全關閉網站後不保證背景同步。

不新增依賴或資料庫 migration。驗證命令與實際結果見 [VALIDATION.md](../VALIDATION.md)，操作見 [OFFLINE.md](../OFFLINE.md)。更新後需關閉所有舊分頁／網站 App 再連線開啟，讓新離線介面接手。
