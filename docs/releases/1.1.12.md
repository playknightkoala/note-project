# 1.1.12 — 幣別欄位與自動幣值換算

新增「幣別」欄位型別，「幣值換算」可以直接跟著金額欄位與幣別欄位自動計算。

- **幣別欄位**　從「新增屬性」或「編輯欄位」選擇「幣別」，再從常見幣別中勾選會用到的幾種。資料格的填寫方式與單選相同。既有的單選欄若選項本來就是幣別代碼（例如 TWD、JPY），可直接改為幣別，資料列不需重填；不是幣別代碼的選項會在儲存時移除，仍有資料列使用時須先改選其他選項。
- **自動幣值換算**　在「幣值換算」欄位的設定中選擇「要換算的金額欄位」，此欄即依該欄的金額自動計算，不需逐格輸入。再選擇「依據的幣別欄位」後，會依每列的幣別換算成另一種幣別：以新台幣與日圓為例，新台幣的資料列顯示日圓金額，日圓的資料列顯示新台幣金額。未填幣別或幣別不在這兩種之內的資料列不顯示結果。未指定金額欄位時，仍可像以前一樣在每格輸入金額。
- **更多幣別**　幣值換算的基準幣別與換算幣別由新台幣、日圓擴充為 18 種常見幣別。

## 注意事項

- 已有手動輸入金額的幣值換算欄位，須先清空才能改為自動換算。
- 金額欄位與幣別欄位被幣值換算使用時，不能刪除或改為其他型別，請先在幣值換算欄位取消指定。
- 自動換算的欄位混有兩種幣別，不能加入「欄位加總」。

## 修正

- 透過 API 只修改欄位的部分設定（例如只改名稱）時，會連帶清空單選欄位的選項。現在只變更請求指定的項目。網頁介面不受此問題影響。

## 升級
