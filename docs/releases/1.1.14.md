# 1.1.14 — 開啟頁面時自動展開子頁面

開啟有子頁面的頁面時，側欄會自動展開它的子頁面，不必再點箭頭。

- **展開範圍**　只展開下一層；更深的子頁面維持收合，開啟那一頁時才展開。
- **開啟方式**　從側欄點選、搜尋、麵包屑、頁面連結或直接以網址開啟都會展開。「與我共用」的頁面也適用。
- **手動收合**　收合後停留在同一頁不會再被展開；離開後再開啟，或再點一次該頁的列，才會重新展開。
- **手機**　點選頁面後側欄照常收起，再打開側欄即可看到子頁面。

## 注意事項

- 沒有子頁面的頁面不受影響。
- 展開狀態和以前一樣記在這台裝置的瀏覽器裡，不會同步到其他裝置。

## 升級

使用 Docker Compose 部署時，更新至此版本後執行 `docker compose up --build --wait`。介面偵測到新版後會先保存修改，再提示「立即更新」。
