# 1.1.13 — 調整欄位順序

資料庫的欄位順序現在可以調整。

- **電腦**　用滑鼠拖曳表頭的欄名，放到另一欄上，它就取代那一欄的位置。拖曳時目標欄邊緣會出現標示線，指出欄位會落在哪一側。
- **手機**　點欄名，在選單選「向左移動」或「向右移動」。電腦的欄位選單與右鍵選單也有這兩項，可用鍵盤操作。
- **名稱欄**　固定在最前面，不能移動；把欄位拖到名稱欄上，會排到第一個屬性欄。

## 注意事項

- 順序屬於資料庫本身：調整後表格、清單、看板與資料列面板都跟著改變，不需要另外儲存視圖。
- 只有資料庫擁有者可以調整順序；共用成員與公開連結不會看到這些選項。
- 離線時也能調整，連線後自動同步。
- 視圖中隱藏的欄位會留在原本相鄰的欄位旁邊。

## 升級

使用 Docker Compose 部署時，更新至此版本後執行 `docker compose up --build --wait`。介面偵測到新版後會先保存修改，再提示「立即更新」。
