# Notes 1.0.4

一般筆記新增 PWA 離線使用與自動同步，並修正桌面側欄「…」選單移入後消失的問題。

## 新增

- 手機與電腦可離線開啟已下載的一般筆記、新增筆記與子頁面，以及編輯標題、區塊內文與文字格式。
- 內容先保存在此裝置，恢復連線或重新開啟後自動同步；介面區分「已存此裝置，待同步」與「已同步」。
- 「離線與同步」提供下載全部一般筆記、待同步清單、手動重試，以及草稿匯出與明確捨棄。
- 同步以版本號及標題基準防止靜默覆寫，衝突時保留草稿；明確覆蓋仍保存被覆蓋的頁面歷史。
- 新增同步操作識別碼與交易紀錄，回應遺失後重試不會重複建立筆記或重複增版；送出期間繼續輸入也會保留後續修改。
- 使用者與附件快取按帳號隔離，不持久保存密碼、session 或 CSRF token。有待同步內容時先阻止登出，避免草稿遭清除。

## 修正

- 桌面側欄「…」選單開啟期間保持定位按鈕可見，滑鼠移入選單後不再消失；右鍵、鍵盤及點外關閉維持正常。
- 標題編輯期間不被背景載入清除，按 Enter 或失焦時完成標題保存。
- 附件 HTTP 快取會重新確認授權，離線快取保留下載及 sandbox 標頭。

## 使用與限制

- 手機需透過 HTTPS 首次連線開啟，等候離線介面準備完成，再下載筆記；從未下載的內容無法直接離線開啟。
- 共同支援的同步方式為「開啟時自動同步」，不保證 iOS／Android 在鎖屏或完全關閉後立即背景同步。
- 資料庫、列屬性、搜尋、留言、圖示／封面等其他頁面設定與新附件上傳仍需連線。
- 附件須先連線開啟才會快取，每檔最多 20 MB、每帳號最近 100 檔；清除網站資料或裝置空間不足可能影響未同步內容。
- 已用 Chrome 手機視口實測離線重開、新增、恢復同步與衝突保護；iOS Safari／Android 實體手機、真實鍵盤與手機 HTTPS 尚待實機驗收。

完整說明見 [離線筆記使用說明](https://github.com/playknightkoala/note-project/blob/v1.0.4/docs/OFFLINE.md)。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up --build --wait
```

本版新增 migration `0007_offline_operations`，啟動時自動套用且可重跑。保留原有資料 volume；不要直接複製使用中的 SQLite 檔。

升級後先連線重新開啟網站；若仍在使用舊的離線介面，先確認草稿已保存，再關閉本站其他分頁並重新開啟，讓新版本接手。
