# 1.1.10 — 費用試算、資料列側窗與頁面搬移

## 在表格換算與加總費用

點選「費用試算」，指定原幣金額、單選幣別與分攤人數欄位，再輸入每 NT$1 可換的原幣數量。也可以指定逐筆匯率欄位。表格會將各筆費用換算為每人台幣，四捨五入到整元。

勾選項目就能查看每人合計，例如只勾選自己入住的房型。分攤人數或匯率缺漏時，表格會標出待補項目。匯率設定會保存在視圖中，勾選供當次比較使用。

## 編輯資料庫與整理頁面

- 編輯既有數字欄位時可切換成「金額」，立即以千分位顯示原有數值。表頭只顯示欄名，單選欄位在選定後自動儲存並關閉。
- 點資料列的開啟圖示，可在桌面右側或手機全寬面板編輯屬性與內文。面板上方可切換到完整頁面。
- 在側欄選「⋯ → 移動到…」，搜尋上層頁面或選「最上層」，即可移動筆記或整個資料庫。桌面也可拖到目標頁面，稍微向右移，看到外框後放開。

## 升級

使用 Docker Compose 部署時，更新至此版本後執行 `docker compose up --build --wait`。介面偵測到新版後會先保存修改，再提示「立即更新」。
