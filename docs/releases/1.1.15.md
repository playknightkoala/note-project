# 1.1.15 — 站內共用邀請與資料庫視圖自動儲存

## 站內共用邀請

輸入對方註冊時使用的 Email、選好權限並按「送出邀請」後，對方會在側欄看到「共用邀請」與待處理數量。受邀者可以查看邀請人、頁面標題及權限，再選擇接受或婉拒。擁有者可以在等待接受時撤回邀請。

受邀者連線接受後，才會透過該邀請取得存取權、在「與我共用」看到筆記，並將共用內容納入離線同步。升級前已加入的成員可繼續使用原有權限。

## 資料庫視圖自動儲存

擁有者套用排序、篩選或勾選顯示欄位後，設定會自動儲存到目前視圖。離線時修改保存在裝置上，重新開啟已下載的資料庫仍看得到，恢復連線後再依序同步。共用者調整這些條件只影響自己的畫面。

## 升級

本版啟動時會自動建立待接受邀請的資料表。使用 Docker Compose 部署時，更新至此版本後執行 `docker compose up --build --wait`。
