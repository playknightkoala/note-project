# 1.1.1 — 知道連結的本站帳號可唯讀或編輯

1.1.0 的站內共用需要逐一輸入對方的 email。這一版在分享視窗的「與本站帳號共用」加入一個選項，讓任何登入本站、且有頁面網址的帳號都能開啟。新增一個資料庫 migration（`0010_share_account_link`），沒有調整任何依賴版本。使用說明見 [SHARING.md](../SHARING.md)。

## 新功能

- **知道連結的本站帳號**：可設為「不開放」（預設）、「知道連結的人皆可唯讀」或「知道連結的人皆可編輯」。連結就是頁面本身的網址（`/p/…`），分享視窗會顯示並可複製。
- 對方必須登入本站帳號；沒有登入的人仍然只能使用公開連結（唯讀）。
- 權限與個別加入的成員相同：唯讀可閱讀、留言、加表情；可編輯另可修改內文、標題、資料列並加入附件。範圍沿用該頁面的分享範圍。
- 開啟過連結的帳號會在側欄「與我共用」看到這個頁面，也會下載到裝置供離線使用；擁有者在分享視窗看得到有哪些帳號開啟過。
- 同一個帳號同時被個別加入、又能透過連結開啟時，取權限較高者。
- 改為「不開放」後，透過連結開啟的帳號立即無法再開啟，個別加入的成員不受影響。

## 注意事項

- 「知道連結的人皆可編輯」等於讓本站所有拿到網址的帳號都能修改這個頁面（與範圍內的頁面）。被取代的內容會留在頁面歷史，擁有者可以還原。
- 頁面網址會出現在瀏覽器紀錄，也可能出現在其他共用頁面內的頁面連結中；不希望被開啟時請維持「不開放」。
- 「設定 → 分享」會標示哪些頁面開放給知道連結的帳號。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up -d --build --wait
```

migration `0010_share_account_link` 會在啟動時自動套用。
