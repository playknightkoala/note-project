# 1.1.9 — 弱網時自動切換離線使用

手機仍顯示有網路，但 Notes 伺服器回應緩慢時，已下載的個人筆記、頁面樹與資料庫會先顯示此裝置上的副本。

## 變更

- 連續兩次網路請求失敗後，顯示「連線不穩，離線使用中」。同步暫停，編輯先保存到此裝置。
- 網站在前景時每 5 秒檢查一次連線。連續三次在 2 秒內成功，且伺服器重新驗證原帳號後，就會自動同步。
- 若登入已過期，網站會關閉編輯畫面並回到登入頁。已保存的草稿會保留，原帳號重新登入後可繼續同步。
- 弱網時重新開啟共用頁面仍需伺服器確認權限。若已收到存取拒絕，網站會停止顯示舊副本。

完全離線時，既有副本仍存放在瀏覽器，伺服器無法即時通知裝置登入已過期或分享已撤權。尚未下載的內容需要連線才能取得。

## 升級

依照既有的 Docker Compose 部署方式更新程式碼並重建容器。這一版無資料庫 migration。介面偵測到 1.1.9 後，會先保存修改，再顯示「立即更新」。
