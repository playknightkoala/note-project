# 1.1.17 — 衝突處理與離線同步的修正

本版沒有新功能，修正 1.1.16 發布後審查找到的問題，都在「版本衝突」與離線同步。

## 版本衝突

- 兩個分頁都顯示同一個衝突時，只有畫面上是最新草稿的分頁可以處理。顯示較舊內容的分頁不能再用它的內容覆蓋，也不能把另一個分頁的草稿丟掉；它會收到提示，請確認內容後再選一次。
- 另一個分頁處理完衝突後，其他沒有未儲存修改的分頁會直接載入結果，不再停在衝突畫面。
- 按下「以我的內容覆蓋」後、等伺服器回應的期間繼續輸入的文字會保留，並在覆蓋之後接著儲存。

## 離線同步

- 離線新建、還沒送到伺服器的頁面遇到衝突提示時，選「以我的內容覆蓋」會以目前的草稿建立頁面。1.1.16 在這種情況下兩個選項都會失敗，頁面無法同步。
- 把被伺服器拒絕的附件從內文移除、再捨棄該附件時，不會先送出一次仍引用該附件的舊內文，改為提示重新選擇。

## 升級

沒有資料庫結構變更。使用 Docker Compose 部署時，更新至此版本後執行 `docker compose up --build --wait`。

升級後請把每個開著的分頁都更新到新版。仍在執行舊版介面的分頁如果剛好有請求還在傳送中，可能在新版分頁處理完衝突之後才送達伺服器；所有分頁更新後就不會發生。
