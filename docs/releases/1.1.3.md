# 1.1.3 — 封面版面調整：標題不再貼著封面，電腦版封面撐滿

有封面的頁面，標題會貼在封面下緣；電腦版的封面也只有閱讀欄的寬度。這一版把兩者改為接近 Notion 的呈現方式。只改前端的版面，沒有資料庫 migration，沒有調整任何依賴版本。

## 變更

- **沒有圖示的頁面**：標題與封面之間留出 40px 的間距，不再貼在一起；滑鼠移上去時「新增圖示」出現在這段空間。
- **有圖示的頁面**：圖示一半壓在封面下緣，下方留出間距再接標題。圖示壓在封面上的那一半原本會被封面遮住，現在完整顯示。
- **電腦版封面撐滿**：封面從側邊欄右邊延伸到視窗右緣，不再只有 900px 閱讀欄的寬度。一般筆記、全寬筆記、資料庫都相同；公開連結頁有左側導覽欄時，封面從導覽欄右邊開始。
- **手機版不變**：封面維持滿版寬、160px 高。
- **分享的頁面**：唯讀與共用編輯的讀者看到的標題位置，和擁有者一致。

## 封面圖片的大小

- 封面高度沒有改變（視窗高度的 30%，介於 200 到 320px）。螢幕越寬，封面越扁長。
- 圖片比封面窄時，會等比例放大到填滿寬度，上下超出的部分裁掉；不會留白，也不會拉伸變形。
- 放大倍數越大越模糊。建議使用寬度 1500px 以上的圖片。
- 「調整位置」照常可用：上下拖曳決定顯示圖片的哪一段；左右固定置中。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up -d --build --wait
```

沒有 migration。已開啟的分頁會出現新版提示，更新後即套用新的版面。
