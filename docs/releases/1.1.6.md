# 1.1.6 — 瀏覽器分頁的標題與圖示跟著頁面

登入後不論開哪一頁，瀏覽器分頁原本都是固定的「Notes」與 LOGO。這一版讓分頁跟著目前的頁面走，寫法與 Notion 相同。只改前端，沒有資料庫 migration，沒有調整任何依賴版本。

## 變更

- **分頁標題**：開啟頁面時是「頁面標題 | Notes」；頁面沒有標題時是「無標題 | Notes」。在頁面上改標題，分頁跟著變。
- **分頁圖示**：頁面有圖示（表情符號）時，分頁圖示就是它；換圖示或移除圖示時立刻更新。頁面沒有圖示時顯示 Notes 的 LOGO。
- **適用的頁面**：一般頁面、資料列頁面、資料庫頁面、別人與你共用的頁面，以及公開連結頁。
- **離開頁面**：回到首頁、垃圾桶或設定時，分頁還原為「Notes」與 LOGO。

## 範圍與限制

- 公開連結頁的分頁標題原本只有頁面標題，現在也加上「 | Notes」。
- 表情符號以裝置自己的字型繪製，在 Windows、Android、macOS 上的樣子不同。
- 首頁、垃圾桶、設定與登入頁沒有各自的分頁標題，維持「Notes」。安裝成 App（PWA）的圖示不變。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up -d --build --wait
```

沒有 migration。已開啟的分頁會出現新版提示，更新後即可使用。
