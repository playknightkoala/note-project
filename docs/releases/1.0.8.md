# 1.0.8 — 資料庫、留言與附件也能離線使用

原本只有一般筆記能離線；這一版讓資料庫、留言與表情反應、筆記中的附件也能離線使用，連線後自動同步。新增一個資料庫 migration，沒有調整任何依賴版本。

## 離線可以做的事

- **資料庫**：所有資料庫（結構、視圖、資料列與列內文）會自動下載到裝置。離線可開啟表格／清單／看板視圖，修改儲存格與列名稱、新增資料列、開啟資料列頁面並編輯內文與屬性，也可新增、修改、刪除欄位與視圖。
- **留言與表情反應**：離線可對選取文字新增討論、回覆、加上或取消表情、標示已解決、刪除整則討論，黃色標記立即顯示。
- **附件**：離線在筆記中加入的圖片與檔案先存在裝置並可立即顯示，連線後先上傳附件，再同步引用它的筆記。
- 離線或有修改尚未同步時，畫面會標示「目前顯示此裝置上的副本」，側欄下方顯示待同步的修改數與待上傳的附件數。

## 衝突與同步

- 資料列改為**逐格比對**：只有同一格（或列名稱）在兩邊都被修改才算衝突；兩台裝置改同一列的不同欄位會自動合併。線上編輯也適用，原本「整列已在其他地方更新」的誤判因此減少。
- 欄位與視圖的修改以資料庫結構版本比對；同一台裝置連續做的修改不會互相衝突。
- 留言只會往後附加，表情與已解決狀態以最後一次為準，不會跳衝突視窗。
- 衝突或被伺服器拒絕的修改留在「離線與同步」清單並顯示原因，可重試、以我的修改覆蓋（需確認）、匯出或捨棄。系統不會自動覆蓋另一台裝置的值。
- 每項修改只會在伺服器執行一次；回應遺失後重送不會重複新增資料列、留言或附件。
- 有尚未同步的筆記、資料庫或留言修改，或待上傳的附件時，會阻止登出。

## 仍需連線

搜尋、頁面歷史、最愛、搬移、垃圾桶（含資料列）、圖示與封面、新增資料庫。

## 注意事項

- 離線加入附件需要已啟用的離線介面（HTTPS 或 localhost）；待上傳的附件只存在該裝置，清除網站資料或瀏覽器回收空間會讓它遺失，請儘早連線同步。
- 資料庫有變動時會重新下載整個資料庫的結構與資料列；列數很多的資料庫，每次變動的下載量較大。
- 自行撰寫的腳本：`POST /api/files` 可帶表單欄位 `id`（UUID）讓上傳可重送；既有的資料庫與留言 API 不變。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up -d --build --wait
```

啟動時會自動套用 migration `0008_offline_receipts`（只前進、可重跑）。伺服器部署後，開著的分頁會收到更新提示；更新後請連線開啟一次，讓資料庫與留言下載到裝置。只建立 GitHub Release 不會更新運行中的容器。
