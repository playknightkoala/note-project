# 1.0.6 — 留言修正、介面版號與立即更新

- 「標示為已解決」後，文字取消黃色；可從「包含已解決／已取消」找到討論並重新開啟。
- 新增「刪除整則討論」，確認後刪除所有留言與反應，保留筆記文字、其他格式與重疊的其他討論。刪除需登入、CSRF 與目前版本，遇到衝突保留資料。
- 移除最後一個表情且沒有留言時，取消黃色。若仍有留言或其他未解決討論，黃色繼續保留。
- 以 ProseMirror decorations 顯示標記，討論狀態更新不改寫筆記內文，也不干擾手機格式工具的選取範圍。快取此裝置最後讀取過的標記狀態，連線／離線重開可維持正確顯示；留言與反應的新增、修改、刪除仍需連線。
- 左下角顯示目前介面版號，點擊可檢查更新；手機可在側欄底部查看。
- 開啟網站、恢復連線、切回前景及每分鐘會檢查已部署的伺服器版本。偵測新版後自動顯示更新說明 Modal，可按「立即更新」或「稍後更新」。
- 立即更新會下載並核對新版，讓新的離線介面接手，再重新載入目前分頁；失敗可重試。更新前保存筆記，保留此裝置的待同步草稿、登入與附件快取。未送出留言、未完成表單、無法保存的修改或附件上傳會先提示處理。
- 其他分頁保留目前內容並收到提醒，不會被另一分頁的更新動作重新載入；它們使用的舊資源會保留到完成更新。

直接依賴固定 `@tiptap/pm@3.33.0`，沿用既有間接依賴版本；沒有升級 BlockNote 或新增資料庫 migration。實際驗證見 [VALIDATION.md](../VALIDATION.md)。

**首次從 1.0.5 或更早版升級，請先連線重新載入一次以載入更新功能。** 後續版本才會自動提示；伺服器仍須先部署新版，單純發布 GitHub Release 不會更新運行中的容器。
