# 1.1.4 — 頁面內尋找與取代

在筆記頁尋找文字原本只能用瀏覽器內建的尋找。這一版加入自己的尋找列，樣式與操作接近 Notion，並且可以取代。只改前端，沒有資料庫 migration，沒有調整任何依賴版本。

## 變更

- **開啟**：在筆記頁按 `Ctrl+F`（macOS `⌘F`），或從頁面選單「尋找與取代」（手機也能用）。尋找列出現在右上角、頂列下方。先選取文字再開啟會自動帶入。
- **尋找**：不分大小寫。所有結果以黃色標出，目前這一筆是橘色，旁邊顯示「第幾筆／總數」。`Enter`／`Shift+Enter`、箭頭按鈕或 `Ctrl+G` 切換結果，會自動捲到該處；結果在收合的折疊列表裡時會展開。
- **取代**：按取代圖示展開「取代為…」。`Enter` 或「取代」只改目前這一筆並跳到下一筆；「全部取代」一次改完，按一次復原（`Ctrl+Z`）就全部還原。取代後的文字沿用原本的樣式，並照常自動保存。
- **關閉**：`Esc` 或 ×。標示會清除，游標停在剛才找到的位置。
- **唯讀的頁面**：唯讀共用頁與公開連結可以尋找，不能取代。

## 範圍與限制

- 只搜尋目前頁面的內文（含表格、程式碼區塊、折疊列表的子項目）。標題、資料列屬性與側邊欄不在範圍內；要跨頁搜尋請用 `Ctrl+K`。
- 資料庫頁面沒有內文，`Ctrl+F` 仍是瀏覽器的尋找。
- 焦點在尋找欄位時再按一次 `Ctrl+F`，會關閉尋找列並改用瀏覽器自己的尋找，可用來找標題等範圍外的文字。
- 尋找的文字不會跨段落，也不會跨過行內的頁面連結。

## 升級

升級前先使用線上備份：

```sh
docker compose exec app node dist/server/cli.js backup
git pull
docker compose up -d --build --wait
```

沒有 migration。已開啟的分頁會出現新版提示，更新後即可使用。
